Task13-NumPy Random Sampling

## Description

This project demonstrates random number generation and random sampling
using NumPy in Python.

## Objective

To understand random data generation and the importance of reproducibility
using random seeds in data science experiments.

## Tools Used

- Python
- NumPy
- Jupyter Notebook

## Topics 

- Random integers
- Random floating-point numbers
- Random numbers within a range
- Random sampling from an array
- Random seed
- Reproducibility
- Simulated student dataset

## Dataset

A simulated student dataset was generated using NumPy.

The dataset contains:
- Student ID
- Marks
- Attendance

## Key Functions Used

- `np.random.randint()`
- `np.random.rand()`
- `np.random.uniform()`
- `np.random.choice()`
- `np.random.seed()`

## Conclusion

This task helped me understand how NumPy can be used to generate random
data, select random samples, and produce reproducible results using a
random seed.
